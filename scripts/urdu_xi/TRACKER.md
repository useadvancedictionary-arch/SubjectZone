# Gulzar-E-Urdu XI — Build Tracker

**Book:** Sindh Textbook Board, Jamshoro — Gulzar-E-Urdu XI (192 PDF pages)
**Book page = PDF page** (footer numeral matches the file number)
**Image-only PDF** — all items are solved from rendered page images
**No printed answer key** — comprehension answers come from the lesson texts;
summaries/essays get model responses and a note that other answers are valid.

Pages 5–9 are teacher guidance; 181–192 are the glossary (فہرست). Neither
contains exercises.

L41 (منیر نیازی) and L42 (احمد فراز) share one مشق printed on pp.174–175
(Q1 two verses each, Q2 vocabulary, Q3 five MCQs); items are split by the
ghazal they refer to, and the vocabulary question is answered per lesson.
The ghazal on p173 has only four couplets in this printing; the standard text
adds one couplet. The couplet on p173 prints ”کیا گنگر“ (standard: ”کیسا نگر“).

Each lesson ends with a **مشق** block: numbered questions, usually
1 (short answers), 2 (خلاصہ), 3 (MCQs), 4 (تشریح), 5 (الفاظ/جملے),
6 (مضمون). Some lessons carry a **سرگرمی** writing-skill page — guidance only,
not numbered questions.


## Conventions

- Item keys: `id, lesson, section, sectionCode ('L01'..'L44'), type
  ('sq'|'mcq'), number, question, answer, explanation, bookPage, options,
  optionsRaw, correctAnswer`. Builder adds `chapter`, `pdfPage`.
- IDs: `gulzar_xi_l01_q1a`, `gulzar_xi_l10_q3-2`, etc.
- MCQs carry four options and `correctAnswer` in `(x) text` form.
- Questions are copied verbatim; printed defects are kept and explained.
